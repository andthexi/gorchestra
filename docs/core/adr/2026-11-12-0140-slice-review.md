# Complete Slices through independent review

Accepted; **unimplemented**. Expedition, runtime and downstream work remain paused.

Review each Slice independently before relying on its work, then review the combined Delivery at the integration boundary, rather than defer both assessments to a lighter Delivery-only review. The selected timing and separate gates cost additional explicit review interactions; a valid passing Slice review completes that Slice through explicit application, not runtime completion or an extra human-acceptance gate. Before completion, requested changes start a new bounded fix interaction on the same unfinished Slice rather than reopen an interaction or introduce new scope, preserving the review history.

A later combined-review failure still blocks merge and does not reopen completed Slices. No Correction/RevisionGate repair workflow is supplied by this decision; its absence is a limitation, not permission to waive gates or rewrite accepted history.
