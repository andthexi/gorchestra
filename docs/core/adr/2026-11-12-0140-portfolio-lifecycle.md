# Grant state-specific lifecycle capabilities

Accepted. Private lifecycle issuance, factory classification, explicit setup/migration, shared shutdown and attribution-bound domain operations are implemented, including Secret protection and Portfolio export/import. Shutdown drains admitted operations through transaction settlement and storage-lock release. See [package status](../../../libs/core/README.md#public-surface).

An unrestricted manager can only reject setup, migration and domain calls at runtime, and a readiness check cannot grant a capability across an await. `PortfolioClient.new` therefore asynchronously acquires one Core-owned storage lifetime and returns a state-specific `PortfolioSetup`, `PortfolioMigration` or ready `PortfolioClient`; explicit successful transitions return a fresh ready view over that same owner instead of mutating a discriminant that callers may already have narrowed. This replaces the unrestricted manager, separate connection/status steps and per-operation or borrowed lifetimes, preventing locally invalid typed combinations without claiming linear ownership or compile-time safety for stale aliases.

Bootstrap retains the lifecycle handle and gives application code an immutable attribution-bound `Portfolio`, not shutdown or rebinding authority. Shutdown closes shared admission, drains admitted work, and joins cleanup; observable cleanup failure leaves admission closed and only a later explicit shutdown retries cleanup. Retained transition views and storage-backed operations recheck authoritative history under storage-wide admission; incompatible history closes ordinary operation admission while preserving shutdown.
