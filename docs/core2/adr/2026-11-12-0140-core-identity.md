# Generate and validate exact Core IDs

## Context

Record references require one exact shared identifier convention; legacy trimming would silently repair invalid inputs.

## Decision

<a id="val-01"></a>

### VAL-01 — Core IDs

**Disposition:** accepted. **Implementation:** unimplemented.

Generate all record IDs with Equipped Instance.createId(); validate exact lowercase 26-character ULIDs using one shared Id contract, including overflow exclusion. No model prefixes, caller-supplied IDs, trimming, normalization, coercion, or second ID dependency. Migration literals have separate author-time generation.

**Recorded rationale:** Identity must remain consistent across records and references without repair.

## Alternatives and supersession

- **VAL-01:** No additional alternative is selected by this record.

## Consequences

Core generates record IDs and rejects malformed/overflow/whitespace-altered values. Migration IDs are author-time literals rather than runtime record creation.

The decision record does not claim runtime verification. Foundation implementation tasks must prove applicable behavior; paused scope requires separate authorization.
