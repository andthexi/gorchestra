# Deliver one incremental stacked PR per task

## Status

Decision disposition: accepted. Individual keyed statements below control mixed records.

Implementation: **partial; prepared D1 branch/worktree exists; commit/push/PR delivery belongs to parent and is not performed here** at D1. Scope: delivery process.

ADR created: 2026-11-12-0140 UTC. Original decision date: unknown; filename time is promotion time, not a reconstructed decision date.

## Context

The user selected one new branch and one incremental PR per task rooted at rework; setting every unmerged child base directly to rework would create cumulative diffs.

## Decision

<a id="proc-01"></a>

### PROC-01 — Linear task stack

**Disposition:** accepted. **Implementation:** partial; D1 documentation authored, parent commit/PR delivery and later task synchronization pending.

Use one new branch and one PR per task, in a linear D1 → 0 → … → 13 stack rooted at rework. D1 uses docs/core-decisions → rework; unmerged successors target their immediate predecessor. Keep runtime tests and corresponding docs with their task; never collapse tasks into one cumulative PR or commit implementation directly to rework/main.

**Recorded rationale:** Incremental PR diffs preserve task ownership and review order.

<a id="proc-02"></a>

### PROC-02 — Verified delivery and controlled merges

**Disposition:** accepted. **Implementation:** partial; D1 documentation authored, parent commit/PR delivery and later task synchronization pending.

Verify scoped checks, exact pushed SHA, PR head/base, incremental diff and checks for each task. Propagate lower-stack fixes bottom-up; rewrite only owned branches if necessary with an exact force-with-lease. Merge only on separate authorization, bottom-up into rework; retarget children after their predecessor lands. Never merge children into an unmerged predecessor or delete branches still serving as bases.

**Recorded rationale:** A branch/PR existing is not evidence its intended revision or base is correct.

<a id="proc-03"></a>

### PROC-03 — Preserve original work

**Disposition:** accepted. **Implementation:** partial; D1 documentation authored, parent commit/PR delivery and later task synchronization pending.

Use isolated task worktrees with one writer. Preserve original root AGENTS edits and ignored notes; never force-add rework. D1 is documentation only; Task 0 owns source scaffolding and dependency installation. No Consumer cutover, real-storage migration, package publication, or Expedition resumption follows from foundation execution.

**Recorded rationale:** The execution authorization is bounded to accepted tasks and does not own unrelated work.
